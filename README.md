### 🩺 Diabetes Data Analysis  
![Diabetes](https://upload.wikimedia.org/wikipedia/commons/0/0a/Python.svg) 

**Repository:** [`diabetes.ipynb`](https://github.com/MartineDomgue/Data-Science-Project1)  
**Technologies:** Python, Pandas, Seaborn, Matplotlib, SciPy  
**Tags:** Data Science · Hypothesis Testing · Statistics · Visualization

Used statistical techniques and data visualizations to explore relationships in a medical dataset measuring diabetes progression over one year. Key tasks included:

- Summary statistics (mean, variance)
- Gender-based boxplot comparisons (BMI, BP, disease progression)
- Correlation analysis (including heatmaps)
- Hypothesis testing (two-sample t-test for gender impact)

🧠 **Key Insight:** Women showed consistently higher BMI and BP, while men displayed greater variation in disease progression (Y). Statistical tests confirmed a significant gender difference.
